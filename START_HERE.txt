QUICK START (3 Easy Steps):

1. Make sure you have Python installed
   - Download from: https://www.python.org/downloads/
   - ✅ Check "Add Python to PATH" during installation

2. Double-click one of these files to start the app:

   Windows users: Double-click "START_APP.bat"
   Mac/Linux users: Double-click "START_APP.sh"

3. Open your web browser and go to:

   http://localhost:5000

That's it! 🎉

================================================================================

WHAT THIS APP DOES:

✅ Extracts financial data from UK company accounts
✅ Shows balance sheet and profit & loss information
✅ Compares current year vs previous year
✅ Downloads data as CSV for Excel
✅ Works completely in your web browser
✅ No coding or terminal commands needed!
